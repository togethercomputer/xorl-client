## 2. No-filler OPSD = amortized latent reasoning

Setup: student emits `prompt + "Answer:" + answer` (no filler, no CoT); teacher answers *after* a private CoT; reverse-KL distills the teacher's answer distribution onto the student's direct answer. This compresses the teacher's multi-step CoT into the student's single forward pass — **amortized/parametric** latent reasoning (algorithm baked into weights, fixed single-pass depth), distinct from *test-time-adaptive* prefill compute.

- **4×4 (solvable in one pass):** monotonic climb to ~0.88 at 128 prompts/step × 101 steps (~13k exposures). `acc_pause ≈ acc_nopause`. Recipe: `student_prefill_count=0`, `opd_hidden_match_coef=0`, `supervise_student_cot=true`, lr 3e-6.
- **5×5 (beyond one pass; SUSPECT — corrupted-serving window, see banner):** at the full 128×101 (~13k-exposure) budget, peaks **~0.48 @ step ~15** then decays *below the untrained base* — ~0.26 @ step50, **~0.12 @ step100** (final n=128 control) — while loss stays flat (0.64→0.25). `empty_frac=0`, `mean_completion_tokens≈11`, `has_digit_frac=1.0` throughout → it emits valid, increasingly-*wrong* answers (overfitting the teacher's answer distribution without being able to compute), **not** an EOS/format collapse. ⇒ the 5×5 no-filler ceiling is **~0.48, early, and unstable** — use early-stop / lower lr; do not train to convergence.

**Implication:** the decisive measurement for "is there room for a buffer?" is the no-filler plateau on a *direct-fail* task. 4×4 plateaus high (buffer moot). 5×5 plateaus low (and degrades) → genuine headroom.

## 4. OPRD — the paper's method vs our (incorrect) implementation

**Paper OPRD** (On-Policy Representation Distillation): student samples a real on-policy response `ŷ ~ π_θ(·|x)`; **both student and teacher forward on the SAME ŷ** (same tokens/positions); layer-averaged, position-masked **MSE on hidden states** at the **last-k (=2000) RESPONSE tokens**, all layers, 1/d-normalized, stop-grad teacher; **OPRD-only (μ=0)** by default (optionally `L_OPD + μ·L_OPRD`). Uses a **genuinely stronger teacher** (e.g. JustRL-1.5B) vs a weaker student (R1-distill-1.5B), same backbone (no projector). It closes the student→teacher gap (e.g. AIME24 32.9→49.8, teacher 50.8) because (a) its gradient is conditionally zero-variance (vs OPD's score-function noise that dominates late training), and (b) it supervises the LM-head null space — structure the output projection compresses away.

**Our K=C "OPRD" (PTC-302B/302Bx) is a DIFFERENT objective.** `teacher_cot_mode=match_cot` + `opd_buffer_equals_cot=true` matches **student pause-buffer-position-i ↔ teacher CoT-position-i** = *different tokens, different sequences* (cross-token "cram the CoT into a pause buffer"); supervises the **buffer**, not the response tail; **self-distill** (no stronger teacher — only privileged CoT *context*); composed as **KL + 100·OPRD**, not OPRD-only. It runs end-to-end but loss plateaus and the in-loop static-buffer eval reads 0.0 — the encoded-reasoning buffer-no-op, **not** the paper's result.

**To test the paper's OPRD on this stack:** point the hidden-match at the **shared response/answer positions** (same `ŷ` tokens) and match student-answer hiddens to the **CoT-informed-teacher** answer hiddens (distill the CoT benefit into the answer computation) — a code change, not a knob. Requires a teacher genuinely better at the supervised positions and, ideally, a task where the student emits a long CoT so "last-k response" has substance (5×5-mult's ~10-token answer is a poor testbed). OPRD-specific config: `opd_oprd_layers=every1` (all 40), `opd_oprd_num_layers=40`, `opd_oprd_last_k`, and run with `rmsnorm_mode=native` + `ce_mode=eager` + `enable_compile=false`.

- **Peak-then-decay diagnostics (added 2026-06-09, motivated by PTC-302Nxx).** The 5×5 no-filler decay (0.11→0.48@step15→~0.12@step89 while loss 0.63→0.23) decomposes as: digit-count correctness 1.00→0.81, lead-5-digit 0.65→0.26, tail-3-digit 0.57→0.39 — i.e. the model *loses base-model skills*, consistent with distilling the teacher's off-manifold conditionals at wrong sampled-answer prefixes (60→90% of answer supervision over the run) plus gradient-dead clamped tokens (`opd_loss_max` pinned at 5.0 every step). Now measurable per step: `opd_kl_answer_{correct,wrong}_mean` + `opd_teacher_entropy_answer_{correct,wrong}_mean` (is the teacher confused at wrong prefixes?), `opd_loss_clamp_frac` (frozen-wrongness mass), `opd_kl_{prompt,buffer,answer}_mean` (~70% of supervised tokens are prompt positions = an anchor-to-base term — is "loss falls" anchor re-tightening or answer learning?), `opd_student_entropy`/`opd_top1_agreement` (now live on the streaming backend), and `eval_samples.jsonl` (all 128 decoded samples/step for digit-level decomposition).
- **Loss ≠ success.** Two failure modes: (i) **EOS reward-hack** — loss falls while the model emits `<eos>` right after the prefix (`empty_frac↑`, `mean_completion→0` or cap); fixed by an answer cue (`student_prefill_suffix="</think>Answer: "` or `"Answer: "`). (ii) **Overfitting** — loss falls while held-out accuracy peaks early then *decays* (the 5×5 no-filler case; `empty_frac=0`, length stable, answers just wrong). Both are caught only by reading the `eval/accuracy` trajectory.
- **OPRD K=C caveat:** the in-loop eval uses a *static* buffer, not K=C, so it reads ~0.0 for the K=C arm regardless of training. Gate the OPRD arm on **loss + `opd_oprd_loss`**, and score it with a dedicated **K=C eval** (a follow-up, not yet in-loop).
- **The pause-vs-nopause control (`acc_pause`/`acc_nopause`/`buffer_delta`) is confounded** (no-pause collapse) — diagnostic only.
